# 🎉Sea-lion-ui组件库
为应用中心和模型中心而生

### install
~~~javascript
npm install sea-lion-ui --save
~~~
### 全局加载组件样式
~~~javascript
// 使用
import { Button, IconFont } from 'sea-lion-ui';
~~~
### 组件亮点
* 用typescript开发，支持参数提示
* 支持tree shaking
